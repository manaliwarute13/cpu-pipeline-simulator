Pipeline Concepts

Instruction Pipelining: Multiple instructions are processed in overlapping stages.

IF — Instruction Fetch: Fetches the instruction from memory.

ID — Instruction Decode: Decodes the instruction and identifies registers.

EX — Execute: Performs the operation or calculates an address.

MEM — Memory Access: Reads or writes memory when required.

WB — Write Back: Writes the result to a register.

Data Hazard: An instruction needs a result from an earlier instruction that is not yet available.
